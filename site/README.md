# Zoggyfin website

The static pages for `zoggyfin.zog-tech.com`: the home page, the privacy policy (`/privacy`)
and the support page (`/support`). The App Store listing links to these pages.

The pages are plain HTML with inline styles. There is no build step and no external request.
Run `docker compose up -d` in this folder to serve them with nginx on port 8798.
