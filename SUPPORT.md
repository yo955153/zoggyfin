# Support

## Ask a question

- **GitHub Discussions.** Ask how to use Zoggyfin, share an idea or show your setup.
  Open the **Discussions** tab of this repository.
- **The website.** [zoggyfin.zog-tech.com](https://zoggyfin.zog-tech.com) has the download page,
  the support page and answers to common questions.
- **Email.** [admin@zog-tech.com](mailto:admin@zog-tech.com) for anything that does not fit in public.

## Report a bug

Open an issue with the **Bug report** form. Please tell us:

- the platform (iPhone, iPad, Mac or web) and its version
- the Zoggyfin version (Settings shows it)
- the Jellyfin server version
- the steps to repeat the problem, and what you expected

Do not post passwords, access tokens, invite links or screenshots of a private server.
Before you post a log, remove the server address and your user name.

## Ask for a feature

Open an issue with the **Feature request** form. Say what you want to do, not only what to build.

## Security problems

Do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## Problems with your Jellyfin server

Zoggyfin is a client. It cannot fix a server problem. For help with the server itself, see the
[Jellyfin documentation](https://jellyfin.org/docs/) and the Jellyfin community.
Zoggyfin is not affiliated with the Jellyfin project.

## Response time

This is a small open-source project. We read every issue, but we cannot promise a reply time.
